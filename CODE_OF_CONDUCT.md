# Contributor Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/) v2.1.

We pledge to make participation a harassment-free experience for everyone. We act and
interact in ways that contribute to an open, welcoming, diverse, inclusive, and healthy
community.

Report unacceptable behavior to `conduct@autonomyproof.io`. All complaints are reviewed
and investigated promptly and fairly.
